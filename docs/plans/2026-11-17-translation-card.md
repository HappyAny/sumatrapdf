# 译文白色卡片与加粗开关

> 沿用 writing-plans 与 subagent-driven-development：实现后先做规格复查，再做质量复查。不要提交 Git。

目标：靠近用户最初参考图的浅灰圆角浮窗、白色译文卡片和紧凑工具条，并提供可记忆的译文加粗选择。

## 界面约定

- 浮窗使用独立浅色外观：浅灰外框、白色译文区、深色文字、细灰边框和留白。PDF 与设置窗口的应用主题不受影响。
- 继续使用原生窗口圆角／阴影，译文区绘制带圆角的白色内卡片。保留五个底部操作及现有字号、自适应、手动尺寸功能。
- 标题行在字号控件旁增加 `B` 按钮，ID 3013，按下状态表示整段译文加粗。默认关闭。设置中加入“译文加粗”复选框，ID 3126。
- 只改变显示字体的 FW_NORMAL / FW_BOLD，不改译文、Markdown、提示词或网络请求。切换后保留选区、滚动、固定状态；手动宽高不被覆盖，自适应高度可按新字体重新计算。
- 新偏好 `TranslatePopupBold = false`，在原版/ng 两个生成器、序列化名单和生成文件保持一致。主设置的保存、取消和仅改外观不重试的行为继续成立。
- 内卡片留白需要纳入实际布局／自动高度计算，最小窗口下九个按钮不重叠，正文仍有可用区域。建议浮窗边距 12、间隔 6、标题约 26、状态约 22、底部按钮约 28 DIP；具体以实际绘制和最小尺寸验证为准。
- 浅色译文区必须在 Light / Dark 阅读器主题下均保持白底深色字。不能修改全局主题或暗色库全局配色。避免暗色子类覆盖白色正文颜色。

## 任务 1：原生外观与偏好

文件：`src/TranslatePopup.cpp`、`cmd/gen-settings.ts`、`cmd/ng-gen-settings.ts`、生成的原版/ng 设置文件。必要的主题适配应通过 `src/DarkMode.h/.cpp` 的局部窗口接口，不编辑第三方暗色库。

1. 增加加粗偏好、B 控件、设置复选框与运行时缓存。字体重建比较中加入字重。切换立即保存和应用，不发 API 请求。
2. 将译文与浮窗界面颜色分开。绘制白色圆角内卡片与细边框，调整 EDIT 的内缩与实际测量。管理画刷和字体资源，防止重绘闪烁或销毁后回调。
3. 主设置草稿中保存加粗值；取消不应用。新增布尔值纳入外观变更判断，不纳入请求变更判断。
4. 诊断可增加 `bold` 与实际 `fontWeight`；继续拆分 fmt，避免超过 32 条格式指令。不得加入 API 或密钥信息。
5. 格式化、重新生成后通知根代理集中构建。不要并发运行 GUI 测试。
