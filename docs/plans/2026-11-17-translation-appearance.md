# 划词翻译字体与浮窗尺寸计划

> 按 subagent-driven-development 执行实现、规格复查、质量复查。不要提交 Git。

目标：译文字体可调，自动高度平稳变化，边框拖动切换到可记忆的手动尺寸。保留翻译请求选项、取消机制及五个底部操作，不加入询问 AI。

## 约定

- 译文字体独立于界面字体。默认 Microsoft YaHei UI，11 pt，8–32 pt 可调。
- 标题行新增 A−、A+ 和“自适应”开关，控件 ID 为 3010、3011、3012。保持 3001–3005 五个底部操作。
- Ctrl+滚轮在译文区域逐级改变字号，Ctrl+0 恢复 11 pt。字号调整只改显示，不发起翻译。
- 自动模式保持设定阅读宽度，按实际换行数计算高度。流式期间最多约每 150–200 ms 调整一次，仅长高；完成后精确适配一次。
- 新请求可以在边界重置高度。长译文达到屏幕可用高度的 70% 后滚动。自动尺寸不得超过当前显示器工作区。
- 用户拖边框完成时切换手动模式；程序定位、自动变化、DPI 变化不应被误记为手动调整。手动尺寸下字体和结果更新不能覆盖用户选定宽高。
- 点击“自适应”重新适配当前译文。手动宽高按 96-DPI 逻辑单位持久化，临时屏幕夹紧不得覆盖偏好。
- UI 阅读偏好保存后立即更新当前浮窗，不重复发送 API 请求；修改请求参数后仍按原逻辑重试。保留设置取消草稿的行为。

## 新设置和控件

在两个设置生成器、序列化名单和生成文件中保持一致：

| 设置                    | 默认               | 范围/用途                        |
| ----------------------- | ------------------ | -------------------------------- |
| TranslatePopupFont      | Microsoft YaHei UI | 译文字体，提供已安装字体的选择   |
| TranslatePopupFontSize  | 11                 | 8–32 pt                          |
| TranslatePopupAutoSize  | true               | 自动高度模式                     |
| TranslatePopupWidth     | 460                | 阅读宽度或手动宽度，330–1600 DIP |
| TranslatePopupHeight    | 350                | 手动高度，180–1200 DIP           |
| TranslatePopupMaxHeight | 70                 | 自动高度占工作区比例，30–90%     |

主设置新增显示区域，控件 ID：3120 字体，3121 字号，3122 自适应，3123 宽度，3124 高度，3125 自动最大高度。已有控件 ID 不变。所有设置的运行时使用点也应防御无效高级设置值。

## 任务 1：原生显示、尺寸与设置

文件：`src/TranslatePopup.cpp`、`src/TranslatePopup.h`（如需）、`cmd/gen-settings.ts`、`cmd/ng-gen-settings.ts`、生成的原版/ng 设置文件。

1. 新增字体、尺寸字段并重新生成、格式化。
2. 增加独立译文字体 HFONT 的创建、DPI 更新、替换与释放。保留界面字体、主题、选区与滚动状态。
3. 增加标题控件和快捷键。改变字号后立即显示当前字号，边界正确禁用或夹紧。
4. 按当前 EDIT 换行与实际字体行高计算自动高度；采用可取消的节流计时器，隐藏/销毁时清理。处理完成状态、错误、长文本和小工作区。
5. 用 WM_ENTERSIZEMOVE / WM_EXITSIZEMOVE 区分真实拖动尺寸与程序调整，保存 DIP 偏好。保持屏幕内定位和 DPI 转换。
6. 增加设置显示区域、验证、草稿及即时应用。只改显示参数时不重新请求 API；请求参数更改仍能重试。所有新增字符串正确释放。
7. 诊断状态可新增有效字号、实际字体像素高度、自动/手动模式、手动 DIP 宽高等非敏感字段。保持已有字段不变。

## 任务 2：原生验收测试

文件：新建 `tests/ad-hoc-translate-appearance.ts`，更新 `tests/translate-test-controls.ts` 及必要的现有测试选择器。

1. 在 v2 程序上先确认新控件测试预期失败，并保存证据。
2. 验证默认显示、字体/字号保存与取消、实际字体高度变化、字号上下界、Ctrl+滚轮和 Ctrl+0。字体调整不能增加请求数量或改变译文。
3. 用短/长和流式译文验证自动高度、阅读宽度稳定、高度上限、节流、完成后可缩小，长文本可滚动。
4. 通过原生拖动循环消息和实际窗口变化验证手动尺寸记忆；后续流、字号、新选区均不覆盖手动宽高；恢复自适应不发请求。
5. 独立临时 appdata 保存、退出、重启，验证字体、模式和 DIP 尺寸加载。检查大字号与最小窗口中控件不重叠、始终在工作区。
6. 保留现有 21 + 4 + 12 个场景的行为。底部五个操作不变；标题的新阅读控件应单独识别。保存截图与 JSON，测试由根代理统一执行，避免擦除共享临时目录。
