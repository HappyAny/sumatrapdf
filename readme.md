## SumatraPDF Reader

SumatraPDF is a multi-format (PDF, EPUB, MOBI, CBZ, CBR, FB2, CHM, XPS, DjVu) reader
for Windows under (A)GPLv3 license, with some code under BSD license (see
AUTHORS).

### Windows 划词翻译

这个 fork 在 PDF 阅读区内显示划词译文。翻译浮窗跟随选区，并与原来的快捷条错开。
使用前可在浮窗设置中填写 Chat Completions 或 Responses 兼容的 API 端点、模型和密钥。
从源码构建和配置方法见 [划词翻译说明](docs/selection-translation.md)。
